# Connect - U -- Alfonso-Perez-Juan-Jimenez

## ¿Qué es Connect - U?:
Es un programa que emula una red social por medio de grafos con el fin de aplicar los conocimientos de diseño de datos y algoritmos en el lenguaje Python.

## Features:
* Agregar amigos a la red social
* Conectar amigos en la red social de forma unidireccional
* Encontrar sugerencias de amigos basados en sus amigos
* Remover amigos de la red social
* Eliminar amigos de la red social

## Tecnología:
+ Python
